# eVIP ECG Reporting
Generating clinical free-text reports from ECG records in the MIMIC-IV dataset: 
* [MIMIC-IV](https://physionet.org/content/mimiciv/3.1/)
* [MIMIC-IV-ECG](https://physionet.org/content/mimic-iv-ecg/1.0/)

This repository is an implementation of an LLM and contrastive learning approach to generating ECG reports.
