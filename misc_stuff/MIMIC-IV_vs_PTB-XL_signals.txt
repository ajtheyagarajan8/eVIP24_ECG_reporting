initial value specifies the value of sample 0 in the signal

Therefore to make MIMIC-IV signal perfectly compatible with a pretrained model on PTB-XL, we should multiply the signal by 1000/200=5 to account for gain difference and subtract all the initial values used in PTB-XL

PTB-XL images were generated from the version of the signal that was downsampled from 500Hz to 100Hz. The 1000 samples still corresponds to 10s. This was called `ecg_plot.plot(ecg, sample_rate = 500, title = ' ', style = 'bw')`. By default the function sets columns=2. Using sampling rate of 500 meant that the max x-value (seconds) is 2*(1000/500) = 4.0. Using the same code for MIMIC-IV, it sets the max x-value to 2*(5000/500) = 20.0. To make both images display the same we can just set sample_rate = 2500 for MIMIC-IV
